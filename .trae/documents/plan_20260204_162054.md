# Rust 跨平台安全密码管理软件开发计划

本项目旨在构建一款名为 `ShieldPass` (暂定名) 的高安全、跨平台密码管理器。

## 1. 项目初始化与架构设计
- **创建 Cargo Workspace**：
  - `shield-core`: 核心库，包含加密、数据库、数据模型。
  - `shield-cli`: 命令行入口。
  - `shield-tui`: 终端交互界面。
  - `shield-daemon`: 后台服务（用于自动填充、全局快捷键）。
- **配置 CI/CD 环境**：
  - 设置 GitHub Actions Workflow (Build, Test, Audit, Release).
  - 配置 `clippy` 和 `rustfmt` 规则。

## 2. 核心功能实现 (shield-core)
### 2.1 数据模型与存储
- **依赖**: `serde`, `uuid`, `chrono`, `rusqlite`/`sqlx`.
- **任务**:
  - 定义 `Entry` 结构体 (UUID, Name, URL, Username, Password, Notes, Tags, Timestamps).
  - 实现 SQLite 数据库初始化与 Schema 版本迁移 (`migrator`).
  - 实现安全的内存处理 (`zeroize`, `secrecy`).

### 2.2 加密与安全架构
- **依赖**: `argon2`, `aes-gcm`, `ring`, `zeroize`.
- **任务**:
  - 实现 Argon2id 密钥派生函数 (KDF).
  - 封装 AES-256-GCM 加密/解密逻辑.
  - 实现主密码验证流程与内存锁定 (mlock).
  - 集成 `ring` 生成安全随机密码.

### 2.3 审计与合规
- **任务**:
  - 设计审计日志表结构 (Action, UUID, Timestamp, Hash).
  - 实现日志签名与防篡改逻辑.

## 3. 命令行接口 (shield-cli)
- **依赖**: `clap`.
- **任务**:
  - 实现子命令: `init`, `add`, `get`, `list`, `edit`, `delete`, `search`.
  - 实现导入/导出 (`import`, `export`, `backup`, `restore`).
    - 支持 KeePassXML, 1PUX, CSV.
    - 导出加密 ZIP.

## 4. 终端交互界面 (shield-tui)
- **依赖**: `ratatui` (基于 crossterm), `tui-input`.
- **任务**:
  - 设计 TUI 布局 (侧边栏、列表、详情、搜索框).
  - 实现快捷键导航与模糊搜索.
  - 集成剪贴板操作 (`arboard`).

## 5. 高级功能
### 5.1 自动填充与快捷键
- **依赖**: `rdev` (或平台特定库), `enigo`.
- **任务**:
  - 实现全局快捷键监听 (Wayland/X11/Windows).
  - 实现模拟键盘输入填充.

### 5.2 二次验证与同步
- **依赖**: `totp-rs`, `reqwest` (WebDAV/S3).
- **任务**:
  - 集成 YubiKey/TOTP 验证.
  - 实现 rclone 兼容的同步逻辑.

## 6. 测试与交付
- **测试**:
  - 编写单元测试 (>85% 覆盖率).
  - 使用 `proptest` 进行模糊测试.
  - 使用 `miri` 检查 unsafe 代码.
- **文档**:
  - 编写 README, 用户手册, 安全白皮书.
- **构建**:
  - 编写构建脚本生成 .msi, .dmg, .deb.

## 执行阶段 1 (本阶段重点)
我们将首先搭建项目骨架，并实现核心的加密存储与数据模型，以及基础的 CLI 功能。
1. 初始化 Cargo Workspace.
2. 添加核心依赖 (`argon2`, `aes-gcm`, `rusqlite`, `clap`).
3. 实现 `Entry` 结构体与数据库 Schema.
4. 实现基础的 `add` 和 `get` 命令以验证加密流程.
